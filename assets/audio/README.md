# Tash Rush audio pack

These original sound effects and the music loop are procedurally synthesized
for Tash Rush. They do not contain third-party samples.

- `place.mp3` — piece placement
- `clear.mp3` — completed line
- `combo.mp3` — combo streak
- `explosion.mp3` — bomb activation
- `gold.mp3` — gold cell reward
- `game_over.mp3` — end of the run
- `button.mp3` — menu interaction
- `achievement.mp3` — achievement reward, ready for UI integration
- `music.mp3` — quiet looping plucked-string theme

Regenerate the pack with `python3 tool/generate_audio.py`. FFmpeg with MP3
support must be available on the development machine.
